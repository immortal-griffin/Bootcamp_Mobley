Potara Customs | Transaction Ledger

A Java-based financial transaction management application built with Java 17, JavaFX, and CSV file storage. The Obsidian Transaction Ledger provides a streamlined dashboard for recording, organizing, searching, and reviewing financial transactions through a custom dark-themed graphical interface.

Overview

The Transaction Ledger was developed as a personal accounting and bookkeeping application for tracking business finances. It allows users to record incoming deposits and outgoing payments, review transaction history, and monitor their overall financial position.

The application features a custom Obsidian-inspired interface with charcoal backgrounds, metallic silver accents, and champagne gold highlights.

Features

Transaction Management

Add new financial transactions through a dedicated entry form.

Record transaction dates and times.

Store transaction descriptions and vendor information.

Categorize transactions as either Deposits or Payments.

Automatically normalize transaction amounts:

Deposits are recorded as positive values.

Payments are recorded as negative values.

Save transactions directly to a CSV file.

Financial Dashboard

Total Deposits: Displays the sum of incoming funds.

Total Payments: Displays the sum of outgoing funds.

Net Total: Calculates the difference between deposits and payments.

Automatically updates financial summaries when transactions are added or filters are applied.

Search and Filtering

Search transactions by vendor or description.

Filter transactions by type.

Filter transactions by vendor.

Filter by predefined date ranges:

- Today

- Yesterday

- This Week

- This Month

- Last Month

- This Year

- Last Year

Select a custom date range.

Transaction Sorting

- Newest First

- Oldest First

- Highest Amount

- Lowest Amount

Data Persistence

- Uses a pipe-delimited CSV file for transaction storage.

- Loads existing transactions when the application launches.

- Appends new transactions to the existing transaction history.

- Maintains transaction records between application sessions.

Design Philosophy

- The Obsidian interface was designed around a clean, understated aesthetic.

- Obsidian: Deep charcoal backgrounds establish the visual foundation.

- Champagne Gold: Highlights important controls, financial figures, and interface elements.

- Metallic Silver: Provides contrast and readability throughout the dashboard.

- Color-Coded Transactions: Deposits and payments receive distinct visual indicators.

- The goal was to create an accounting interface that feels organized, professional, and easy to navigate without unnecessary visual clutter.
